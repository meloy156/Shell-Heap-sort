# Сортировка: метод Шелла и пирамидальная
# Поиск: метод Бора

Лабораторная работа по курсу «Алгоритмы и структуры данных» 1.
Реализация двух алгоритмов сортировки и поиска на C++ с экспериментальным
сравнением их временной сложности.

## Что внутри

- `Shellsort.cpp` / `Shellsort.h` — метод Шелла (обменный вариант).
- `Heapsort.cpp` / `Heapsort.h` — пирамидальная сортировка (heapsort).
- `Trie.cpp` / `Trie.h` - поиск по Бору 
- `metodSella.cpp` — главный файл: генерирует случайные массивы,
  замеряет время работы обоих алгоритмов, выводит таблицу.

## Как собрать

Требуется компилятор с поддержкой C++17 (MSVC, g++, clang++).

### MSVC (Windows)

```bash
cl /EHsc /Zi metodSella.cpp Shellsort.cpp Heapsort.cpp /Fe:program.exe
